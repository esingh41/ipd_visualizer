IPD Visualizer

Upload requirements

Upload a .pkl or .pickle containing a pandas DataFrame. Column names are case- and space-sensitive; use the exact names below.

Minimum

  • The DataFrame must be non-empty and include qcel_molecule.
  • At least one row must contain a qcelemental.Molecule dimer with exactly two fragments. Monomer A atoms must come first, contiguously and in order, followed by monomer B atoms.
  • system_id is optional. It groups related rows into a trajectory; without it, each row is shown as a separate single-frame system.

Atomic multipoles

A and B columns are joined for the isolated-monomer view. The dimer column supplies the in-dimer view; provide all three to also see their difference. Every array must use the same atom order as qcel_molecule.

Charges and charge labels

  • q hf/adz A
  • q hf/adz B
  • q hf/adz dimer

One scalar per atom: A (n_A,), B (n_B,), and dimer (n_A + n_B,).

Dipole table and overlays

  • mu hf/adz A
  • mu hf/adz B
  • mu hf/adz dimer

One 3-vector per atom: A (n_A, 3), B (n_B, 3), and dimer (n_A + n_B, 3).

Volume-ratio table

  • volume ratios A
  • volume ratios B
  • volume ratios dimer

One scalar per atom: A (n_A,), B (n_B,), and dimer (n_A + n_B,).

IPD computation

Each row needs all eight isolated-monomer input columns:

  • q hf/adz A
  • q hf/adz B
  • mu hf/adz A
  • mu hf/adz B
  • theta hf/adz A
  • theta hf/adz B
  • volume ratios A
  • volume ratios B

These are per-monomer arrays in atom order: charges and volume ratios contain one scalar per atom, dipoles one 3-vector, and quadrupoles one 3 × 3 tensor. Dimer columns are not required for IPD. Computation also requires a compatible apnet_pt installation on the server; volume ratios alone are not sufficient.
